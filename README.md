# AR 보물찾기

학교 안에서 즐기는 AR 보물찾기 게임 프로젝트입니다.

## 직접 수정하는 흐름

1. VS Code에서 이 폴더를 엽니다.
2. `app/page.tsx`에서 화면과 버튼 동작을 수정합니다.
3. `app/globals.css`에서 색상·배치·애니메이션을 수정합니다.
4. VS Code에서 `Ctrl+Shift+P` → `Tasks: Run Task` → `게임 실행 (개발 모드)`를 선택합니다.
5. 브라우저에서 `http://localhost:3001`을 열면 저장할 때마다 화면이 갱신됩니다.

## 주요 파일

- `app/page.tsx`: 게임 화면과 버튼 기능
- `app/globals.css`: 전체 디자인
- `public/`: 이미지·아이콘 등 게임 에셋
- `components/`: 재사용할 UI 컴포넌트

## Codex와 함께 작업하기

코드 일부를 선택해서 “이 버튼을 다음 미션 화면으로 연결해줘”처럼 요청하거나, 파일 경로와 함께 개선점을 말하면 해당 부분만 함께 수정할 수 있습니다. 변경 전후를 확인하고 싶다면 “수정한 코드 보여줘” 또는 “변경점 설명해줘”라고 요청하세요.
